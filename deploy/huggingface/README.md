# IOC Graph

Upload a threat intelligence report and get a knowledge graph you can explore. Indicators are
extracted with regular expressions, entities and relationships come from Claude, and every claim
the model makes is verified against the source text before it reaches the graph.

Source and full documentation: <https://github.com/karansoni08/ioc-graph>

**Access is gated by a password.** This Space holds the owner's API key and spends real credits, so
it is shared by invitation only.
